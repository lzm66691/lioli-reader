① 安装到平板 / 手机（离线可用）

1
用平板浏览器（Edge / Chrome）打开阅读器网址：lzm66691.github.io/lioli-reader/
2
等待 15–30 秒，让页面后台预缓存（首次打开稍慢属正常）。
3
点浏览器右上角菜单 ⋮ → 「添加到主屏幕」（Chrome）或 「安装应用」（Edge）。
4
桌面出现阅读器图标，之后离线也能打开（已下载的 PDF 仍可读）。
💡 安装后想更新：重新打开线上网址（有网时），顶栏版本号会变到最新；旧版本号说明缓存没刷新，强刷或重装一次即可。
顶栏左上角显示版本号（v16），用它判断是否最新版

② 书架与本地书导入

书架

  • 左栏第 3 个 Tab 是书架：书按分组排列（C 语言讲义 / 本地书等），点分组标题可折叠/展开。
  • 书卡片下方有阅读进度条，点任意书直接打开续读。

导入 PDF（本地书）

1
点书架顶部的「导入 PDF」按钮，选择平板/电脑里的 PDF 文件。
2
导入后出现在「本地书」分组，点开即读；数据存在浏览器本地，不会上传公网。
⚠️ 扫描版教材（如高数/线代图片版）也能导入阅读；本地书若带 PDF 书签大纲，会自动生成目录。

③ 目录（章/节树形）

  • 左栏第 1 个 Tab 是目录：有书签大纲的书自动生成章→节树形目录。
  • 点章标题折叠/展开小节；点节直接跳转到对应页。
  • 翻页后，目录会自动展开当前所在章并高亮当前节。
  • 大纲只有章级的书会提示「本书大纲仅章级」；无大纲的书提示「没有内置书签大纲」。
目录按章/节分层，可折叠跳转

④ 阅读

  • 翻页：PDF 内滚动 / 滑动；顶栏输入页码直接跳转（如输入 15 回车）。
  • 缩放：PDF 内 Ctrl + 滚轮（触控板双指）。
  • 全屏：顶栏「全屏」按钮或按 F。
  • 系统打开：顶栏「系统打开」用系统阅读器打开当前 PDF（pdf.js 异常时兜底）。

⑤ 标注（重点）

阅读器支持两种标注方式，按 PDF 类型选择：

方式一：划词标注（文字版 PDF）

1
用鼠标 / 手指选中一段文字（文字版 PDF 才能选中）。
2
选区上方弹出工具条：三个颜色按钮（暖黄 / 淡粉 / 雾蓝）+「笔记」。
3
点颜色 = 生成高亮；点「笔记」= 输入备注。
选中文字后自动弹出三色 + 笔记工具条

方式二：区域标注（扫描版教材 / 图片版）

1
扫描版（高数/线代等）选不中文字，请点顶栏「框选」按钮进入框选模式（按钮变亮，屏幕顶部出现提示）。
2
按住拖动，画一个框把要标注的内容框住（出现蓝色虚线框）。
3
松手弹工具条 → 点颜色或「笔记」→ 生成区域标注。
4
标注完成后点「框选」按钮退出（恢复翻页）。
💡 不点「框选」时，长按页面约 0.3 秒再拖动也能画框（适合偶尔标一处）。
框选模式下拖动画框，松手选色/写笔记

标注管理

  • 左栏第 2 个 Tab（收藏夹）里能看到标注列表：每条显示页码 + 颜色 + 内容，可跳回该页或删除。
  • 点 PDF 页面上的标注色块可直接删除该条标注。

⑥ 笔记与书签

  • 顶栏「笔记」打开笔记面板：给当前页写笔记，翻页自动切换。
  • 「收藏本页」按钮把当前页加入书签，收藏夹列表里一键跳回。

⑦ 主题切换

  • 顶栏「日间 / 夜间」按钮切换三套主题：日间（白）、夜间（深色护眼）、米黄（纸质感）。
  • 设置自动保存，下次打开保持。
书架分组 + 阅读进度，顶栏可切主题

⑧ 搜索

  • 左栏第 4 个 Tab 是搜索：输入关键词，在目录标题中即时过滤（书签/标注标题也可搜）。
  • 点结果直接跳到对应页。

⑨ 常见问题

问题解决
PDF 加载不出来校园网连 GitHub 慢：本机用 localhost:8920，平板同网用 100.87.159.50:8920（电脑端服务开启时）
扫描版选不中文字正常现象：扫描版是图片，请用「框选」区域标注
本地书没有目录PDF 无内置书签大纲则无法自动生成；有的大纲只有章级，会提示
版本号不是最新强刷（Ctrl+F5）或重装 PWA 应用
标注怎么删除点页面上的标注色块，或收藏夹标注列表点「删」
