03:34(A+B)ᵀ = Aᵀ + Bᵀ 与 (kA)ᵀ = kAᵀ（同段含第二、第三条）：相加的转置朝里带直接分开；数乘的转置数直接朝外提（提公因子只提一次）
05:27(AB)ᵀ = BᵀAᵀ 引入（第一大坑）：相乘的转置朝里带，里边的矩阵要交换顺序

07:12(ABC)ᵀ = CᵀBᵀAᵀ：三个矩阵相乘的转置，顺序全部反转（ABC → CBA）
08:19(Aᵏ)ᵀ = (Aᵀ)ᵏ：例 (A³)ᵀ = (AAA)ᵀ = AᵀAᵀAᵀ = (Aᵀ)³——先幂再转置与先转置再幂一样
09:17反对称行列式复习（主对角线为轴上下对应成相反数、主对角线元素全 0）+ 奇数阶反对称行列式值 = 0（第一章性质）+ 对称矩阵定义：Aᵢⱼ = Aⱼᵢ
11:12对称定义举例：Aᵢⱼ = Aⱼᵢ（例 A₂₃ = A₃₂）；主对角线元素 Aᵢᵢ = Aᵢᵢ 恒成立
12:59A 与 Aᵀ 完全一样 ⟹ Aᵀ = A + 对称矩阵主对角线元素为任意数；随后引入反对称矩阵定义：Aᵢⱼ = −Aⱼᵢ
14:17反对称矩阵主对角线元素必须全为 0 的推导：Aᵢᵢ = −Aᵢᵢ ⟹ 2Aᵢᵢ = 0 ⟹ Aᵢᵢ = 0
15:33反对称矩阵常用判定：Aᵀ = −A（逐元素差一个负号）+ 口诀：说对称想 Aᵀ=A，说反对称想 Aᵀ=−A
16:11性质①：A、B 同阶对称 ⟹ A±B 对称；性质③（同段）：A、B 同阶对称，AB 对称 ⟺ AB=BA（可交换）
18:35性质④：AᵀA 与 AAᵀ 必对称（A 为任意 m×n 矩阵，无需对称）
19:30反对称矩阵的幂：A 反对称，(Aᵏ)ᵀ = (Aᵀ)ᵏ = (−A)ᵏ = (−1)ᵏAᵏ——k 偶 → Aᵏ 对称，k 奇 → Aᵏ 反对称
21:20例证：A 反对称 → A¹⁰ 对称（(−1)¹⁰=+1）、A¹⁵ 反对称（(−1)¹⁵=−1）
