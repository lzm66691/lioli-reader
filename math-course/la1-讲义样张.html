LA-1 二阶行列式与三阶行列式

对应 1.1 二阶·三阶行列式（P1，28.7min）· 自写学习整理：基于宋浩《线性代数》3.0 课程的学习索引，不含原课程素材 · 本节目标：20 分钟读懂 + 40 分钟练完

① 本节定位与前置

行列式是线性代数的"第一块砖"：后面求矩阵的逆、解线性方程组（克拉默法则）都要算行列式。前置要求：会解二元一次方程组（加减消元）、会算简单乘法。

本节学完你会：手算二阶/三阶行列式，一眼看出上三角、下三角、对角型行列式的值，并知道"行列式 vs 矩阵"的符号区别——这个区别贯穿全书，是最大的扣分点之一。

② 概念与定义

二阶行列式：从方程组"长"出来的新运算

求解二元一次方程组时，把 X 和 Y 的表达式整理后，分子分母都长成"四个数，两两相乘再相减"的样子。数学家就把这种形式定义成一个新运算：

二阶行列式定义：四个数 a₁₁、a₁₂、a₂₁、a₂₂ 按"行、列"排好，外面加两条竖线，规定它等于"主对角线两数相乘 − 副对角线两数相乘"：

a₁₁a₁₂a₂₁a₂₂ ＝ a₁₁·a₂₂ − a₁₂·a₂₁

其中 aᵢⱼ 叫元素：i 表示第 i 行、j 表示第 j 列。读作"a 一 一、a 一 二"，不是"a 十一"。

易错提示 1（符号）：外面是两条竖线才是行列式；小括号 / 中括号是矩阵。同一个数字表，竖线=行列式（一个数），括号=矩阵（一张数表）——全书最容易混的符号。
易错提示 2（中间是减号）：二阶行列式 = 主对角线相乘 减去 副对角线相乘，减号不能丢。例：|1 2; 3 4| = 1×4 − 2×3 = −2（不是 2×3 加 1×4）。

三阶行列式：对角线法则（三正三负）

三行三列共 9 个元素。展开式共 6 项：3 个正项 + 3 个负项，每一项都是"取三个数相乘"。取法按下面六条线走：

项取法
正项 1主对角线：a₁₁·a₂₂·a₃₃
正项 2a₁₂·a₂₃·a₃₁（从右上撇下来，注意方向）
正项 3a₁₃·a₂₁·a₃₂
负项 1a₁₃·a₂₂·a₃₁（从左上撇到右下反向）
负项 2a₁₁·a₂₃·a₃₂
负项 3a₁₂·a₂₁·a₃₃
记忆：正项从左上往右下方向撇，负项从右上往左下方向撇。每次取恰好 3 个数——连线撇过头取到 4 个数就错了。

③ 定理与适用条件

结论内容适用条件
上三角行列式主对角线左下方全为 0，值 = 主对角线元素相乘三阶及以上都成立（本章先会用三阶）
下三角行列式主对角线右上方全为 0，值 = 主对角线元素相乘同上
对角型行列式只有主对角线有元素，值 = 主对角线元素相乘同上
易错提示 3（方向）：只有"左上↘右下"这条方向上的非零元素才叫对角型；元素在"右上↗左下"方向上的不是对角型，不能直接乘，要老老实实按对角线法则展开。

④ 例题（含易错提示）

例 1：二阶行列式求未知数（λ）

计算 |λ−1　2; 3　λ+4| = 0，解 λ。

解：(λ−1)(λ+4) − 2×3 = λ² + 3λ − 4 − 6 = λ² + 3λ − 10 = 0 → (λ+5)(λ−2) = 0 → λ = −5 或 λ = 2。

套路：先按对角线法则展开成普通方程，再解——行列式只是"包装"，算完就是一元二次方程。

例 2：三阶行列式直接展开（课后题 123/231/312）

按对角线法则展开 |1 2 3; 2 3 1; 3 1 2|：

正项：1·3·2 + 2·1·3 + 3·2·1 = 6+6+6 = 18；负项：3·3·3 + 1·1·1 + 2·2·2 = 27+1+8 = 36；结果 = 18 − 36 = −18。

易错提示 4（计算量大易错）：三阶直接展开 6 项，数字一复杂就错。做题策略：元素里有 2 个或以上 0，直接展开（很多项自动消失）；全不为 0 且数字复杂，等学了行列式性质（1.3）再化简，不硬算。

例 3：上三角一眼出答案

|1 2 3; 0 6 9; 0 0 3| 是上三角 → 值 = 1×6×3 = 18。

⑤ 一分钟自测

自测（想清楚再翻答案）：
1. 二阶行列式 |2 5; 1 4| = ？
2. 三阶行列式 |1 0 0; 0 2 0; 0 0 3| = ？
3. 判断题：|1 2; 3 4| 用小括号写成矩阵形式后，值还是 1×4−2×3。（对/错）
答案：1. 2×4−5×1 = 3　2. 对角型 → 1×2×3 = 6　3. 错——行列式才是"算值"的数，矩阵是数表，没有"值"；符号不能混。
