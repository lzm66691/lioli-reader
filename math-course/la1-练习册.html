LA-1 练习册 · 二阶三阶行列式

配合《LA-1 讲义》使用 · 题型：概念填空 → 判断改错 → 计算 → 应用 · 全部为自写变式题 · 参考解答含"思路 + 常见错法" · 建议 40 分钟

一、概念填空（填一填，把定义钉死）

1.二阶行列式 abcd 的值等于 ______ ，其中 ad 所在的线叫 ______ 对角线，bc 所在的线叫 ______ 对角线。
2.行列式外面用的是 ______（符号），矩阵外面用的是小括号或 ______。行列式最终是一个 ______，矩阵是一张 ______。
3.三阶行列式展开共有 ______ 项，其中 ______ 个正项、______ 个负项；每一项是 ______ 个数相乘。
4.元素 a₂₃ 表示位于第 ______ 行、第 ______ 列；读作 ______（不是"a 二十三"）。
答案：1. ad−bc；主；副　2. 两条竖线；中括号；数；数表　3. 6；3；3；3　4. 2；3；a 二 三

二、判断与改错（专治"看起来对"的错）

5.判断对错并说明理由：|1 2; 3 4| 和 (1 2; 3 4) 是同一个东西，值都是 −2。
6.判断对错：|0 0 2; 0 3 0; 4 0 0| 是对角型行列式，值 = 0×3×0 = 0。
7.改错：某同学计算 |2 3; 1 4| 写：2×4 + 3×1 = 11。错在哪？正确值是多少？
答案：5. 错——竖线是行列式（值 −2），括号是矩阵（数表，没有值），记号不同意义不同　6. 错——元素在"右上↗左下"方向，不是对角型；按对角线法则展开 = −2×3×4 = −24　7. 错在中间是减号不是加号；正确 2×4 − 3×1 = 5

三、计算（动手算，练六条线）

8.计算二阶行列式 |3 −1; 2 5|。
9.解方程：|x 2; 3 x+1| = 0，求 x。
10.用对角线法则展开三阶行列式 |1 0 2; 0 3 0; 4 0 1|（先看有几个 0，再决定展开方式）。
11.上三角 |2 1 1; 0 3 2; 0 0 5| = ？（不许展开，直接写结论）
12.计算 |a 1 0; 0 b 1; 1 0 c|（含字母的三阶，按六条线逐项写）。
答案（思路+常见错法）：
8. 3×5 − (−1)×2 = 15 + 2 = 17（错法：把减号漏掉，写成 15−2=13）
9. 展开：x(x+1) − 2×3 = x² + x − 6 = 0 → (x+3)(x−2) = 0 → x = −3 或 2（错法：忘展开成方程直接猜）
10. 含 5 个 0，直接展开只剩带非零元素的项：正项 1·3·1 + 0 + 0；负项 2·3·4 + 0 + 0 → 3 − 24 = −21（错法：0 项也硬写 6 项，算错概率大增）
11. 上三角 → 主对角线相乘 = 2×3×5 = 30（错法：把上三角当普通三阶展开）
12. 正项：a·b·c + 1·1·1 + 0；负项：0 + 1·b·1 + 0 → abc + 1 − b（错法：负项 2 写漏或方向撇反）

四、应用（行列式进方程组）

13.二元一次方程组 2x + 3y = 1、3x + 4y = −2 的系数行列式是 |2 3; 3 4|，其值为 ______。若把它当分母，用"常数项替换第一列"的分子行列式是 |1 3; −2 4|，其值为 ______，则 x = ______。
14.拓展思考（不要求算）：三阶方程组 a₁₁x+a₁₂y+a₁₃z=b₁ 之类，为什么克拉默法则要求系数行列式 ≠ 0？结合"行列式做分母"想一想。
答案：13. 系数行列式 = 2×4 − 3×3 = −1；分子 = 1×4 − 3×(−2) = 10；x = 10 ÷ (−1) = −10（错法：分子分母算反/符号乱）　14. 行列式做分母，分母为 0 时式子无意义——所以克拉默法则的使用前提就是系数行列式不为 0（先记住，P6 细讲）。
