{

        n++;

参考答案

① 012。
思路：i=0,1,2 各打一次，i=3 时条件为假退出（讲义 6.2）。
② 5。
思路：n=5 时条件 5<5 已为假，循环体一次不执行，直接打印 5（讲义 6.1 的 while 先查条件）。
③ 4 次（打印 "hi hi hi hi"）。
思路：i=2 时 continue 跳过本次的 printf，其余 4 轮照常（讲义 6.4）。
④ 诊断（本机 gcc 16.1.0 实测）：2 处问题，其中 1 处编译期只有 warning、运行直接"卡死"。
  1. 第 7 行 while (n < 5);——while 后多了个分号，循环体变成空语句 ;，大括号里的打印成了"跟在后面的普通代码块"。编译期 gcc 只给 warning: this 'while' clause does not guard...（警告，不是错误），运行时 n 永远不变 → 死循环卡死。修复：删掉分号；
  2. 第 6 行 int n = 0;——就算修好分号，输出是 0 1 2 3 4 而不是想要的 1..5。想打印 1..5 应 int n = 1;（条件 <= 5）。
修复 = 删分号 + n 从 1 开始。修复版输出（实测）：1 2 3 4 5 done。教学点：死循环编译期往往看不见（只有 warning 甚至没 warning）——改完代码先想想"条件会变假吗"，再运行。
⑤ 参考代码： 
ch6_p6_sum.c
#include <stdio.h>

int main(void)
{
    int sum = 0;
    for (int i = 1; i <= 100; i++) {
        sum += i;
    }
    printf("1+2+...+100 = %d\n", sum);
    return 0;
}
思路：计数器 i 从 1 到 100，每轮 sum += i。常见错法：把 i <= 100 写成 i < 100（少加 100）；或 sum 忘了初始化成 0（残留值）。实测输出：5050。
⑥ 参考代码： 
ch6_p7_power.c
#include <stdio.h>

int main(void)
{
    int p = 1;
    for (int i = 1; i <= 5; i++) {
        p *= 2;
        printf("2^%d = %d\n", i, p);
    }
    return 0;
}
思路：p 每轮乘 2，正好是 2 的幂。常见错法：每轮 p = 2 * i（那是 2i 不是 2 的 i 次方）。实测输出：2,4,8,16,32。
⑦ 参考代码（循环读成绩）： 
ch6_p8_avgloop.c
#include <stdio.h>

int main(void)
{
    int score, count = 0;
    double sum = 0.0;
    printf("输入成绩（0 结束）：");
    while (scanf("%d", &score) == 1 && score != 0) {
        sum += score;
        count++;
    }
    if (count > 0)
        printf("共 %d 门，平均 = %.1f\n", count, sum / count);
    else
        printf("没有输入成绩\n");
    return 0;
}
思路：条件里 scanf == 1 检查"读到了数字"（防乱输入），score != 0 是终止信号。常见错法：把 0 也算进成绩（先判 0 再累加）。实测输出：共 2 门，平均 = 87.5。
