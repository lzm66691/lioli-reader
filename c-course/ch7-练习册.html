#include <stdio.h>

int main(void)
{
    int score = 85;
    if (score >= 90)
        printf("优秀\n");
    else if (score = 80)          /* 想表示 80 分及以上得"良好" */

参考答案

① A。
思路：n=3 是赋值不是判断（恒为真），所以走 if 打印 A。要判断相等该写 n==3（讲义 7.1 新手坑 1）。
② P。
思路：85>=60 第一个条件就为真，后面 else if 不会再查——先写宽条件会吃掉后面的窄条件（讲义 7.2 的顺序坑）。想得 G 应把 >=80 放前面。
③ yes。
思路：c=='b' 为真，|| 一边真即真（讲义 7.4）。
④ 诊断（本机 gcc 16.1.0 实测）：第 9 行 else if (score = 80) 同一行有两层错。
  1. 赋值当判断：score = 80 把 80 赋给 score，条件恒真——不管输入多少都走"良好"。gcc 实测报 warning: suggest parentheses around assignment used as truth value [-Wparentheses]（编译能过，逻辑全错）；
  2. 范围错：就算把 = 改成 ==，85 分 score == 80 为假，会掉到 else 打"加油"。想表达"80 分及以上"应该用 score >= 80。
修复 = score = 80 → score >= 80（一步同时解决两层错）。修复版输出（实测）：良好。教学点：看到 = 出现在 if 条件里先警惕；另外 == 只能匹配一个精确值，范围判断要用 >=。
⑤ 参考代码： 
ch7_p6_grade.c
#include <stdio.h>

int main(void)
{
    int score = 72;
    if (score >= 90)      printf("优秀\n");
    else if (score >= 80) printf("良好\n");
    else if (score >= 70) printf("中等\n");
    else if (score >= 60) printf("及格\n");
    else                  printf("不及格\n");
    return 0;
}
思路：从高到低排（90→80→70→60），第一个满足的生效。常见错法：从低到高排（60→70），72 分会被先判成"及格"。实测输出：中等。
⑥ 参考代码： 
ch7_p7_calc.c
#include <stdio.h>

int main(void)
{
    double a, b;
    char op;
    printf("输入 数字 运算符 数字（如 3 + 5）：");
    scanf("%lf %c %lf", &a, &op, &b);
    switch (op) {
        case '+': printf("%.1f %c %.1f = %.1f\n", a, op, b, a + b); break;
        case '-': printf("%.1f %c %.1f = %.1f\n", a, op, b, a - b); break;
        case '*': printf("%.1f %c %.1f = %.1f\n", a, op, b, a * b); break;
        case '/': printf("%.1f %c %.1f = %.1f\n", a, op, b, a / b); break;
        default:  printf("不支持的运算符\n");
    }
    return 0;
}
思路：switch 按字符分流。常见错法：case 后忘 break（掉穿，讲义 7.3 新手坑 2）。实测输出：3.0 + 5.0 = 8.0。
⑦ 参考代码（元音计数）： 
ch7_p8_vowel.c
#include <stdio.h>

int main(void)
{
    char ch;
    int count = 0;
    printf("输入一行英文：");
    while ((ch = getchar()) != '\n' && ch != EOF) {
        if (ch == 'a' || ch == 'e' || ch == 'i' || ch == 'o' || ch == 'u' ||
            ch == 'A' || ch == 'E' || ch == 'I' || ch == 'O' || ch == 'U')
            count++;
    }
    printf("元音共 %d 个\n", count);
    return 0;
}
思路：循环读字符直到换行，逐个比对元音。常见错法：忘写大小写（只查小写，'E' 漏算）；或把 != '\n' 写成 ==（循环体一次不执行）。实测：hello world 共 3 个元音。
