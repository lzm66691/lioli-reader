12-2 改错（★★，先自己找再对答案）

改错★★

下面程序有 4 处问题，找出并改正，分类为「编译期报错 / 仅警告 / 静默逻辑错」：

#include <stdio.h>
#include <stdlib.h>

int main(void)
{
    int n = 5, i;
    static int x = n;             /* ① */
    int *arr = malloc(n);         /* ② */
    int *p = malloc(10 * sizeof(int));  /* ③ */
    for (i = 0; i < n; i++) arr[i] = i * 2;
    for (i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("x=%d\n", x);
    return 0;                     /* ④ */
}

提示：static 初始化时机 / 忘记 sizeof / 申请了不用 / 申请了不还。

12-7 参考答案（先自己写，再看思路与常见错法）

12-1

依次填：块、自动、静态、只一次、文件、堆、free。
思路：作用域回答「哪能用」，存储期回答「活多久」；static 改存储期不改作用域（块内 static 仍只在本块可见）。
常见错法：把「static 让变量变全局」记错——它只是活得久，可见范围不变。

12-2

四处问题及实测诊断（gcc 16.1.0 -Wall -Wextra 实测）：

① static int x = n;        编译期报错：initializer element is not constant
   （static 初始化必须是编译期常量，不能是运行时变量 n）
② malloc(n) 忘 sizeof     静默逻辑错：无诊断。只分到 n 字节却当 n 个 int 用，
   堆写越界（后果隐蔽）
③ int *p = malloc(...); 不用  仅警告：unused variable 'p' [-Wunused-variable]
   （顺带：这 10 个 int 也没 free → 泄漏）
④ 全程没 free            静默逻辑错：无诊断。arr 和 p 都泄漏，
   程序退出前内存一直在涨

改法：① 写成 static int x = 0;（或编译期常量）；② malloc(n * sizeof(int)) 并检查 NULL；③ 删掉 p 或真正用它并在结束前 free；④ 结尾 free(arr); free(p);。
常见错法：把「没 free」当小事——长跑程序（嵌入式/服务端）泄漏到 OOM 是真实事故；-Wall -Wextra 抓不住 ②④，全靠自己养成「malloc/free 成对」习惯。

12-3

思路：static 局部计数器，每次调用 +1 并返回。

#include <stdio.h>
int next_frame(void){
    static int n = 0;
    n++;
    return n;
}
int main(void){
    int i;
    for (i = 0; i < 5; i++) printf("帧号:%d ", next_frame());
    printf("\n");
    return 0;
}

常见错法：忘了 static 导致每次重置（输出全 1）；把 static 放函数外当全局用（会改变可见范围）。

12-4

思路：malloc 按 n 申请 → 读入 → 求均值（sum/(double)n）和最大 → free。

#include <stdio.h>
#include <stdlib.h>
int main(void){
    int n, i, *a, max, sum = 0;
    printf("n=? ");
    scanf("%d", &n);
    a = malloc(n * sizeof(int));
    if (a == NULL) return 1;
    printf("%d 个数：", n);
    for (i = 0; i < n; i++) scanf("%d", &a[i]);
    max = a[0];
    for (i = 0; i < n; i++){ sum += a[i]; if (a[i] > max) max = a[i]; }
    printf("平均 = %.1f  最大 = %d\n", sum / (double)n, max);
    free(a);
    return 0;
}

常见错法：sum / n 整数除法；malloc 后不检查 NULL；忘了 free。

12-5

思路：malloc(n) 字节 → 循环填 'A' → 打印前 3 个 → free。

#include <stdio.h>
#include <stdlib.h>
int main(void){
    int n, i;
    char *buf;
    printf("缓存大小 n=? ");
    scanf("%d", &n);
    buf = malloc(n);
    if (buf == NULL) return 1;
    for (i = 0; i < n; i++) buf[i] = 'A';
    printf("缓冲前 %d 字节：", n < 3 ? n : 3);   /* 护栏：n<3 时只打印 n 个，绝不越界读 */
    for (i = 0; i < 3 && i < n; i++) printf("%c ", buf[i]);
    printf("\n");
    free(buf);
    return 0;
}

常见错法：char 申请不用乘 sizeof（sizeof(char)=1 恒成立，写了也对）；malloc 后忘记检查 NULL 就直接用 buf[0]。
延伸：真实串口缓冲常用「环形队列」，先掌握 malloc/free 配对，数据结构课再深入。
