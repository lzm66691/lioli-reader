9-7 参考答案（先自己写，再看思路与常见错法）

9-1 填空答案：① 返回类型 / void；② 复制；③ 函数原型；④ 提前结束；⑤ 指针 / 长度 n。
9-2 改错答案： 
/* debug_exercise_109_fixed.c — 修好的版本 */
#include <stdio.h>

double average(int a, int b, int c);

int main(void)
{
    int x = 7, y = 9, z = 4;
    printf("avg = %.2f\n", average(x, y, z));
    return 0;
}

double average(int a, int b, int c)
{
    double sum = a + b + c;      /* 错误1：sum 要是 double，否则整数除法丢小数 */
    return sum / 3.0;            /* 错误2：除 3.0 而不是 3，触发浮点除法 */
}                                /* 错误3：main 里 %f 与 double 匹配，但补了 %.2f 更规范 */
三处错误：①int sum 应为 double sum；②sum / 3 应为 sum / 3.0（整数除法丢小数）；③printf 的 %f 可配 %.2f 让输出更清晰（第 3 处也可算「格式不规范」）。
本机 gcc 16.1.0 -Wall -Wextra 实测：fixed 版输出 avg = 6.67；原版输出 avg = 6.000000（静默丢小数，无警告——正是「静默错误」的典型）。
9-3 编程参考：核心 int m = a; if (b>m) m=b; if (c>m) m=c; return m;。常见错法：用 a>b?a:b 嵌套但括号写错；漏处理相等情况（不影响结果）。
9-4 编程参考：for (int i=0; i<n; i++) if (arr[i]>0) cnt++;，返回 cnt。常见错法：忘了 const；用 sizeof(arr)/sizeof(arr[0]) 取长度（新手坑 3，必须传 n）。
9-5 专业场景参考：
void blink_led(int pin, int times)
{
    printf("pin %d\n", pin);
    for (int i = 0; i < times; i++)
    {
        printf("LED 亮\n");
        printf("LED 灭\n");
    }
}
常见错法：把「LED 亮/灭」循环次数想成 2×times（输出 8 行）——题目只要交替 times 次。
