参考答案

① 4 字节；约 21 亿（2147483647）。
思路：32 位 = 4 字节。上界 2^31-1。
② %lf；%f。
思路：scanf 里 double→%lf、float→%f，写反读出来乱码（讲义 3.6）。
③ 65；'B'（66）。
思路：字符就是 ASCII 数字，'A'+1='B'（讲义 3.4）。
④ 诊断（本机 gcc 16.1.0 实测）：本题编译能过（exit=0），但有 1 个警告 + 2 处"看起来对实际错"。
  1. 第 6 行 int height = 1.75;——用 int 存小数，1.75 被"静默截断"成 1。这是数据错误，gcc 默认 -Wall -Wextra 不报（需 -Wconversion 才提示），属"静默"类，最危险。应 double height = 1.75;；
  2. 第 7 行 printf("我的身高 %f 米\n", height)——%f 配 int，gcc 报 warning: format '%f' expects 'double' but argument has type 'int' [-Wformat=]（编译期可见的"警告"）；
  3. 第 7 行 %f 默认 6 位小数，会打出 1.750000——若想打 1.75 用 %.2f（格式问题，不算错但体验差）。
结论：本题编译能过 ≠ 程序正确。修复 = double height = 1.75; + printf("我的身高 %.2f 米 ", height)，输出「我的身高 1.75 米」。教学点：int 存小数的"静默截断"编译器默认发现不了——error/仅警告/静默三类里最难防的一类。
⑤ 参考代码： 
ch3_p5_circle.c
#include <stdio.h>

int main(void)
{
    const double PI = 3.14159;
    double r = 5.5;
    printf("r = %g, 圆面积 = %f\n", r, PI * r * r);
    return 0;
}
思路：const 防止手滑改 PI。常见错法：给 PI 用 %d（乱码）；或忘加 const。
⑥ 参考代码： 
ch3_p6_bmi.c
#include <stdio.h>

int main(void)
{
    double h, w;
    printf("输入身高(米)和体重(kg)：");
    scanf("%lf %lf", &h, &w);
    printf("BMI = %.2f\n", w / (h * h));
    return 0;
}
思路：一次 scanf 读两个值，中间空格分隔。常见错法：用 %f 读 double（乱码，讲义 3.6）。
⑦ 参考代码（ADC 电压换算）： 
ch3_p7_adc.c
#include <stdio.h>

int main(void)
{
    unsigned int adc = 2048;
    double volt = adc / 4095.0 * 3.3;
    printf("ADC=%u, 电压 = %.2f V\n", adc, volt);
    return 0;
}
思路：除以 4095.0（带 .0）强制转成浮点运算，否则 adc/4095 是整数除法会得 0。这是嵌入式最经典的整数除法坑。常见错法：写 adc / 4095 * 3.3——整数除法先算，结果恒 0。
