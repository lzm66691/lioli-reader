11.1 先看一个真实场景：程序要处理「名字」

你写一个考勤程序，要读入同学名字、统计长度、比较两个名字是否相同。C 语言里「名字」不是一种内置类型，而是字符数组 + 结尾的 \0。这一章就是把这套东西讲透——之后读传感器字符串指令（串口 AT 指令）、解析日志行，全靠它。

11.2 字符串是什么：char 数组 + '\0'

字符串字面量 "hi" 实际是 3 个字节：'h' 'i' '\0'——末尾那个 \0（值为 0 的字符）叫空字符，是字符串的「句号」，函数靠它知道到哪结束：

/* ch11_01_str.c — 字符串就是 char 数组 */
#include <stdio.h>

int main(void)
{
    char name[] = "hi";          /* 自动变成 {'h','i','\0'}，3 个元素 */
    char word[8] = {'h', 'e', 'y', '\0'};   /* 手动：必须有 \0 结尾 */

    printf("%s | %s\n", name, word);
    printf("name 占 %zu 字节\n", sizeof(name));   /* 输出 3（含 \0）*/
    return 0;
}

实测输出：hi | hey　name 占 3 字节。注意 sizeof(name) 是 3（含 \0），而 strlen(name) 是 2（不含）。

数组长度 ≥ 内容长度 + 1：留一位给 \0。char s[5] 最多存 4 个字符 + \0。

11.3 字符串的读写：printf / scanf / fgets

输出用 %s；输入有两个选择，新手必用 fgets：

/* ch11_02_io.c — scanf 遇空格停 vs fgets 读整行 */
#include <stdio.h>

int main(void)
{
    char a[32], b[32];
    int c;

    printf("输入一行（含空格）：");
    scanf("%s", a);               /* 危险：读到空格就停，且不检查长度 */
    while ((c = getchar()) != '\n' && c != EOF) {}  /* 清掉 scanf 留在缓冲区的回车；EOF 时退出，防重定向死循环 */

    printf("再输入一行：");
    fgets(b, sizeof(b), stdin);   /* 安全：读一整行，最多 31 字符+ \0 */

    printf("scanf 读到: %s\n", a);
    printf("fgets 读到: %s", b);  /* fgets 会保留结尾换行 */
    return 0;
}
新手坑 1：scanf("%s") 两个雷：①遇到空格就停（"Li Ming" 只读到 "Li"）；②不限制长度，输入超长会越界写坏内存（缓冲区溢出）。所以读一行用 fgets，别用 scanf %s。
新手坑 2：fgets 会把结尾 \n 也存进来。想去掉它：size_t len = strlen(b); if (len > 0 && b[len-1] == '\n') b[len-1] = '\0';——这是处理 fgets 的标配三行。
新手坑 3：清缓冲区必须防 EOF。上面 while ((c = getchar()) != '\n' && c != EOF) 里的 c != EOF 不能省——若输入被重定向或结束（如 ./a.exe < data.txt、判题系统喂数据），getchar() 会一直返回 EOF，不带 EOF 判断就会死循环。用 int c 接收（不能是 char，EOF 是负值）。

11.4 字符串函数：strlen / strcpy / strcmp / strcat

函数作用示例
strlen(s)长度（不含 \0）strlen("hi") → 2
strcpy(dst, src)把 src 复制到 dststrcpy(b, a);
strcmp(a, b)比较内容：0 相等 / <0 a 小 / >0 a 大if (strcmp(a, b) == 0)
strcat(dst, src)把 src 接到 dst 末尾strcat(b, "!");

这些函数在 #include <string.h> 里：

/* ch11_03_funcs.c — 字符串函数全家桶 */
#include <stdio.h>
#include <string.h>

int main(void)
{
    char a[] = "Li", b[32] = "";

    strcpy(b, a);                       /* 复制：b = "Li" */
    strcat(b, " Ming");                 /* 拼接：b = "Li Ming" */

    printf("%s（长度 %zu）\n", b, strlen(b));
    printf("比较 a 和 \"Li\"：%d\n", strcmp(a, "Li"));   /* 0=相等 */
    return 0;
}

实测输出：Li Ming（长度 7）　比较 a 和 "Li"：0。

新手坑 3：strcmp 比的是内容，不是地址。if (a == "Li") 比较的是两个地址（永远不相等），必须 strcmp(a, "Li") == 0。同理 == 不能用来比字符串。
新手坑 4：strcpy/strcat 不检查空间。目标数组太短会越界写坏内存。稳妥做法：目标数组开大一点 + 用 strncpy/strncat（带长度版本）。

11.5 遍历字符串：逐个处理字符

配合循环可以数单词、找字符、统计字母：

/* ch11_04_count.c — 统计字母个数（\0 是循环的终点）*/
#include <stdio.h>
#include <string.h>

int main(void)
{
    char line[] = "Hello, LZU 2026!";
    int letters = 0;

    for (int i = 0; line[i] != '\0'; i++)
        if ((line[i] >= 'a' && line[i] <= 'z') || (line[i] >= 'A' && line[i] <= 'Z'))
            letters++;

    printf("字母数：%d\n", letters);   /* H e l l o L Z U = 8 */
    return 0;
}

实测输出：字母数：8。循环条件 line[i] != '\0' 是遍历字符串的标准写法；也可以用 i < strlen(line)（每次重算长度，稍慢）。

11.6 新手坑集中营（本章最容易错的 4 件事）

  • 1. scanf("%s") 遇空格停 + 不查长度：读一行用 fgets；读了超长输入会缓冲区溢出（越界写坏相邻变量）。
  • 2. 数组长度不够放 \0：char s[5] 存 5 个字符会丢 \0 → 之后 strlen 越界乱读。永远「内容长度 + 1」。
  • 3. strcmp 用 == 代替：a == "Li" 比的是地址，必须 strcmp(a,"Li")==0。
  • 4. 中文按字节处理：UTF-8 下一个汉字 3 字节，strlen("你好")=6 不是 2；%10s 宽度按字节，中文对齐会错位。需要处理中文时按字节流操作，别按「字数」想。
