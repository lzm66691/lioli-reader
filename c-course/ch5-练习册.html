参考答案

① 2；2.5；2。
思路：10/4 两个 int → 整数除法截断得 2；10.0/4 有 double → 2.5；10%4 余数 2（讲义 5.2）。
② 8；16。
思路：a += 3 等价 a = a + 3（讲义 5.4）。
③ n % 7。
思路：整除 ⟺ 余数为 0。口诀：/ 取商，% 取余（讲义 5.2）。
④ 诊断（本机 gcc 16.1.0 实测）：2 处编译错误 + 1 处逻辑错误。
  1. 第 8 行 printf("7 / 2 = %f\n", half) 漏分号——gcc 报 error: expected ';' before 'num'，报错行指向第 9 行（漏分号总是"错在下一行"，见 Ch1 讲义 1.4）；
  2. 第 9 行 num = num + 1 漏分号——修复后编译器继续，报 error: expected ';' before '}'；
  3. 第 7 行 num / 2 是整数除法，half 想得 3.5 实际得 3.0（编译不报错，属"输出不对"）。改成 num / 2.0。
修复 = 两处补 ; + num / 2.0。修复版输出（实测）：7 / 2 = 3.500000、num = 8。教学点：先修编译错误（分号），再找逻辑错误（整数除法）——别被编译器带偏，修完能编译 ≠ 程序算对了。
⑤ 参考代码： 
ch5_p6_avg.c
#include <stdio.h>

int main(void)
{
    double c = 82.5, math = 91, eng = 78;
    double avg = (c + math + eng) / 3.0;
    printf("平均分 = %.1f\n", avg);
    return 0;
}
思路：除以 3.0（带 .0）保小数。常见错法：写 / 3——整数除法会把 251.5/3 截断成 83。实测输出：平均分 = 83.8。
⑥ 参考代码： 
ch5_p7_time.c
#include <stdio.h>

int main(void)
{
    int total = 3661;
    int h = total / 3600;
    int m = (total % 3600) / 60;
    int s = total % 60;
    printf("%d 秒 = %d 小时 %d 分 %d 秒\n", total, h, m, s);
    return 0;
}
思路：三步拆：总秒数 ÷3600 得小时；余数再 ÷60 得分钟；最后余数即秒。常见错法：m = total % 60（把 61 秒算成 1 分 61 秒——分钟不是对 3600 取余后再拆）。实测输出：3661 秒 = 1 小时 1 分 1 秒。
⑦ 参考代码（电阻分压）： 
ch5_p9_divider.c
#include <stdio.h>

int main(void)
{
    double vin = 5.0;
    int r1 = 1000, r2 = 2000;
    double vout = vin * r2 / (r1 + r2);
    printf("Vout = %.2f V\n", vout);
    return 0;
}
思路：让 vin * r2 先算（int 变 double），再除——避免 r2 / (r1+r2) 先做整数除法得 0。常见错法：照抄公式顺序 r2 / (r1 + r2) * vin——整数除法先执行，Vout 恒为 0。实测输出：Vout = 3.33 V。
