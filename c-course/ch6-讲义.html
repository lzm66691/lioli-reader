Ch6 C控制语句：循环

对应《C Primer Plus（第6版）》第 6 章 · 本章目标：30 分钟读懂 + 60 分钟练完 · 不覆盖：goto、逗号表达式

6.1 while 循环：条件成立就一直做

程序最强大的能力是重复。让计算机打印 1 到 10，不需要写十行 printf——用循环。最基础的是 while：

/* ch6_01_while.c — while 数数 */
#include <stdio.h>

int main(void)
{
    int n = 1;
    while (n <= 5) {        /* 条件为真就进循环体 */
        printf("%d ", n);
        n++;                /* 计数器 +1，否则死循环 */
    }
    printf("\n");
    return 0;
}

运行输出（实测）：1 2 3 4 5

while 的套路是三件套：

  1. 初始化：进循环前先把计数器设好（int n = 1;）；
  2. 条件：while (条件)——为真继续，为假退出；
  3. 更新：循环体里改计数器（n++）——忘了它 = 死循环。
新手坑 1：死循环。条件永远为真就无限循环（程序"卡住"）。急救：按 Ctrl+C 中断。写 while 前先问自己：这个条件有办法变假吗？

6.2 for 循环：三件套写在一行

for 把「初始化、条件、更新」三个部件放进一对括号，中间用分号隔开，是计数循环最常用的写法：

/* ch6_02_for.c — for 求和 1+2+...+10 */
#include <stdio.h>

int main(void)
{
    int sum = 0;
    for (int i = 1; i <= 10; i++) {   /* 初始化; 条件; 更新 */
        sum += i;
    }
    printf("1+2+...+10 = %d\n", sum);
    return 0;
}

运行输出（实测）：1+2+...+10 = 55

部件说明示例
初始化进循环前执行一次，通常声明计数器int i = 1
条件每次进入前检查，为真继续i <= 10
更新每轮循环体结束后执行i++
口诀：「从几开始，到几为止，每次怎么变」——for (开始; 条件; 变化)。C99 起可以在 for 里直接声明 int i，循环结束 i 就"消失"。

6.3 do-while：至少做一次

有时候你想「先干一次，再问要不要继续」——用 do-while。它和 while 唯一的区别：条件检查在循环体后面，所以循环体至少执行一次。

/* ch6_03_dowhile.c — do-while 至少执行一次 */
#include <stdio.h>

int main(void)
{
    int n = 10;
    do {
        printf("执行了一次，n = %d\n", n);
        n++;
    } while (n <= 3);      /* 条件为假，但循环体已执行过 */
    return 0;
}

运行输出（实测）：执行了一次，n = 10

6.4 break 和 continue：循环里的"刹车"和"跳过"

  • break：立即跳出整个循环（不再管条件）；
  • continue：跳过本次循环体剩余部分，直接进下一轮。
/* ch6_04_breakcont.c — 找第一个能被 7 整除的数（break）/ 只打印偶数（continue）*/
#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 100; i++) {
        if (i % 7 == 0) { printf("第一个 7 的倍数：%d\n", i); break; }
    }
    for (int i = 1; i <= 6; i++) {
        if (i % 2 != 0) continue;   /* 奇数跳过，不打印 */
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}

运行输出（实测）：第一个 7 的倍数：7　2 4 6

6.5 嵌套循环：循环套循环（九九乘法表）

循环体里还可以是循环——叫嵌套循环。外层走一步，内层走一整圈。经典例子是打印九九乘法表：

/* ch6_05_table.c — 九九乘法表（上半部分）*/
#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 3; i++) {          /* 外层：行 */
        for (int j = 1; j <= i; j++) {      /* 内层：列，只到 i */
            printf("%d*%d=%d  ", j, i, j * i);
        }
        printf("\n");
    }
    return 0;
}

运行输出（实测）：

1*1=1
1*2=2  2*2=4
1*3=3  2*3=6  3*3=9
读法：i=1 时内层跑 1 次；i=2 时内层跑 2 次；i=3 时跑 3 次——"外层控制行，内层控制列"。

6.6 新手坑集中营（本章最容易错的 4 件事）

  1. 死循环：忘更新计数器或条件恒真。while (1) 是故意的死循环（嵌入式里常用），别的都是 bug。
  2. while 后面多加分号：while (n <= 5); { ... }——分号让循环体变空语句，条件一直不变 → 死循环（或一次都不执行）。
  3. 条件写成赋值：while (n = 5) 是把 5 赋给 n（条件恒真）；判断相等要用 ==。
  4. for 的三段用逗号：for (int i=1, i<=5, i++) 是语法错误——三段之间是分号，不是逗号。
