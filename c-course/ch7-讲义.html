Ch7 分支和跳转

对应《C Primer Plus（第6版）》第 7 章 · 本章目标：30 分钟读懂 + 60 分钟练完 · 不覆盖：goto、条件运算符嵌套

7.1 if / else：让程序"做选择"

循环让程序会重复，分支让程序会判断。最基础的是 if：条件为真做一件事，否则做另一件事。

/* ch7_01_if.c — if / else 判断成绩是否及格 */
#include <stdio.h>

int main(void)
{
    int score = 76;
    if (score >= 60) {
        printf("及格，继续加油！\n");
    } else {
        printf("不及格，需要补考\n");
    }
    return 0;
}

运行输出（实测）：及格，继续加油！

新手坑 1：== 和 = 写反。判断相等要用 ==（两个等号）。写 if (score = 60) 是把 60 赋给 score——结果恒为"真"，编译器通常只给 warning，程序逻辑完全错。这是 C 初学者最经典的一坑。

7.2 else if：多分支"排队判断"

判断不止两种情况时，用 else if 一路排下去，从上到下第一个为真的分支执行，其余跳过。

/* ch7_02_elseif.c — 成绩等级 */
#include <stdio.h>

int main(void)
{
    int score = 85;
    if (score >= 90)      printf("A\n");
    else if (score >= 80) printf("B\n");
    else if (score >= 70) printf("C\n");
    else if (score >= 60) printf("D\n");
    else                  printf("F\n");
    return 0;
}

运行输出（实测）：B

读法：从上往下问"够不够 90？够不够 80？"——第一个"够"就停。条件有顺序：先写大的再写小的（如果先写 >=60 再写 >=90，90 分会被误判成 D）。

7.3 switch-case：按值"一键分路"

当判断的是"一个变量的值等于几"（而不是大小比较），switch 比一串 else if 更清晰。注意：每个 case 末尾都要 break，否则会"掉下去"执行下一个 case。

/* ch7_03_switch.c — 菜单选择 */
#include <stdio.h>

int main(void)
{
    int choice = 2;
    switch (choice) {
        case 1: printf("打开文件\n"); break;
        case 2: printf("保存文件\n"); break;
        case 3: printf("退出程序\n"); break;
        default: printf("无效选择\n");
    }
    return 0;
}

运行输出（实测）：保存文件

新手坑 2：case 里忘写 break。写 case 1: printf("打开"); 不加 break，选 1 会把"保存文件"也打出来（fall-through 掉穿）。多数情况下这是 bug。

7.4 逻辑运算符：&& || !

把多个条件组合起来：

运算符含义示例
&&并且（两边都为真才真）score>=60 && score<100
||或者（一边为真就真）ch=='y' || ch=='Y'
!取反（真变假，假变真）!done
/* ch7_04_logic.c — 判断闰年（能被4整除且不被100整除，或能被400整除）*/
#include <stdio.h>

int main(void)
{
    int year = 2024;
    if ((year % 4 == 0 && year % 100 != 0) || year % 400 == 0)
        printf("%d 是闰年\n", year);
    else
        printf("%d 不是闰年\n", year);
    return 0;
}

运行输出（实测）：2024 是闰年

7.5 字符输入：getchar 与"字符判断"

程序还能读单个字符并判断。常用的 getchar() 读一个字符，返回它的 ASCII 值。字符在 C 里就是数字，可以直接比较。

/* ch7_05_getchar.c — 读字符判断是数字还是字母 */
#include <stdio.h>

int main(void)
{
    printf("输入一个字符：");
    char ch = getchar();
    if (ch >= '0' && ch <= '9')
        printf("是数字\n");
    else if ((ch >= 'a' && ch <= 'z') || (ch >= 'A' && ch <= 'Z'))
        printf("是字母\n");
    else
        printf("是其他字符\n");
    return 0;
}

运行输出（实测，输入 5）：是数字

原理：字符 '0'~'9' 的 ASCII 是 48~57，'a'~'z' 是 97~122，'A'~'Z' 是 65~90（Ch3 讲过）。ch >= '0' 就是拿数字比较，无需背 ASCII 码表。

7.6 新手坑集中营（本章最容易错的 4 件事）

  1. == 写成 =（见 7.1）——判断相等用双等号。
  2. switch 忘 break（见 7.3）——case 会掉穿。
  3. 悬空 else：else 跟最近的那个 if 配对，不是跟缩进对齐的那个。拿不准就加大括号。
  4. else if 顺序颠倒（见 7.2）——先写宽条件会把后面的窄条件吃掉。
