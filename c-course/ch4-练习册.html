4-1 填空（★）

填空★

在横线处填入正确的占位符，使输出符合右侧注释：

int    n = 7;
double pi = 3.14159;
char   ch = 'A';

printf("____", n);        /* 输出：7 */
printf("____", pi);       /* 输出：3.14 */
printf("____", ch);       /* 输出：A */
printf("____", "hi");     /* 输出：hi */

4-2 改错（★★，最有价值的一题）

改错★★

下面的程序有 4 处问题（编译错误、警告或逻辑错误），找出并改正，然后说明每一处属于「编译期报错 / 仅警告 / 静默逻辑错误」中的哪一类：

#include <stdio.h>

int main(void)
{
    int    score = 92.5;          /* ① */
    char   name[3] = "Lim";       /* ② */

    printf("分数：%d 及格率：%f", score, 0.85);
    scanf("%d", score);           /* ③ */
    printf("姓名：%s", name)      /* ④ */
    return 0;
}

提示：一处静默丢掉小数、一处数组越界（编译器会警告）、一处少了 &、一处少了分号。

编程★★

写程序：读入体重（kg，整数）和身高（m，浮点数），输出 BMI = 体重 ÷ 身高²，保留 1 位小数。
输出样例：

请输入体重(kg)和身高(m)：70 1.75
BMI = 22.9

4-4 编程（★★★）

编程★★★

写程序：读入两个整数 a、b，用 %8d 和 %-8d 各打印一行（观察右对齐/左对齐区别），并打印它们的和与积。
输出样例：

请输入两个整数：123 4567
123|4567 （8 位右对齐）
123 |4567 （8 位左对齐）
和 = 4690 积 = 561741

4-5 专业场景拓展（★★，不需要硬件知识）

拓展★★

串口调试经常要按固定格式打印数据帧。用循环模拟打印 3 帧，格式：帧号=1 数据=xx 校验=0x3f（校验随便算个值即可，这题只练格式化输出）：

帧号=1 数据=0x12 校验=0x4f
帧号=2 数据=0x34 校验=0x6d
帧号=3 数据=0x56 校验=0x8b

要求：帧号用 %d，数据用 0x%02X（十六进制大写两位）。写完后试把 %02X 改成 %X，观察输出差在哪。

4-7 一分钟自测答案

① 错：%d 配了 double，输出是垃圾值；应用 %f。
② 错：scanf 读入必须传地址，应写 scanf("%d", &num)。

4-8 参考答案（先自己写，再看思路与常见错法）

4-1

依次填：%d、%.2f、%c、%s。
思路：占位符按「值的类型 + 想要的显示格式」配对——整数 %d、小数 %.2f（保留两位）、单字符 %c、字符串 %s。
常见错法：把 %f 配 int（输出乱码），或把 %d 配 double；写 %.2f 时忘了小数点前的数字。

4-2

四处问题及分类（莉已用 gcc -Wall -Wextra 实测，诊断与题目一一对应）：

① int score = 92.5;   静默逻辑错：无任何诊断，92.5 被截成 92，小数丢了
② char name[3] = "Lim";  仅警告：initializer-string truncates NUL terminator
   （4 字符装进 3 格，没有 \0 位置，%s 打印会越界）
③ scanf("%d", score);  仅警告：format '%d' expects 'int *' but argument is 'int'
   （少了 &。编译能过但运行时会从无效地址读，直接崩/UB）
④ printf("姓名：%s", name)  编译期报错：expected ';' before 'return'（少了分号）

改法：① 改成 double score = 92.5; 并把 %d 换成 %.1f；② 数组开大 char name[8]；③ 写 scanf("%d", &score)；④ 行尾加分号。
常见错法：以为「编译过了就没问题」——①③ 编译都过但一个是丢数据、一个是运行崩溃，这正是 -Wall -Wextra 存在的意义（③ 会被它抓住）。

4-3

思路：先 scanf 读入两个值（注意 %d 读 int、%lf 读 double），再算 bmi = w / (h*h)，用 %.1f 输出。

#include <stdio.h>
int main(void){
    int w; double h, bmi;
    printf("请输入体重(kg)和身高(m)：");
    scanf("%d%lf", &w, &h);
    bmi = w / (h * h);
    printf("BMI = %.1f\n", bmi);
    return 0;
}

常见错法：scanf("%d%lf", &w, &h) 写成 %f 读 double（scanf 不会像 printf 那样自动提升）；或忘写 &；或算 BMI 时 int 除 int 得整数（这里 w 是 int、h*h 是 double，自动转 double，没踩这个坑）。

4-4

思路：读入后用 printf("%8d %-8d\n", a, b) 观察两种对齐，再打印和与积。

#include <stdio.h>
int main(void){
    int a, b;
    printf("请输入两个整数：");
    scanf("%d%d", &a, &b);
    printf("%8d %8d\n", a, b);   /* 右对齐 */
    printf("%-8d %-8d\n", a, b); /* 左对齐 */
    printf("和 = %d  积 = %d\n", a + b, a * b);
    return 0;
}

常见错法：把 %-8d 写成 -%8d；忘了宽度数字是「最小宽度」，数字超出时不会截断。

4-5

思路：数据写进数组（或直接循环用 0x12 / 0x34 / 0x56），%02X 保证十六进制两位（不足补 0），帧号用 %d。

#include <stdio.h>
int main(void){
    unsigned char data[3] = {0x12, 0x34, 0x56};
    int i;
    for (i = 1; i <= 3; i++)
        printf("帧号=%d 数据=0x%02X 校验=0x%02X\n", i, data[i-1], (unsigned char)(data[i-1] * 3 + 1));
    return 0;
}

常见错法：用 %X 时 0x12 会显示成「12」（丢前导 0）；%02X 与 %02x 大小写不同——数据帧协议常约定大写。
试做后观察：把 %02X 改成 %X 后，帧里的 0x12 会变成 1 个字符「12」（原本占两位），输出不再整齐。
